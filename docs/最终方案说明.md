# 脑纹识别最终方案说明

## 最终版本

- 最终模型：`v4`
- 最终 Excel：`outputs/submissions/test_submission_v4.xlsx`
- 逐任务指标：`outputs/reports/final_v4_metrics.csv`
- 测试逐样本预测：`outputs/reports/final_predictions_v4.csv`

## 官方数据处理口径

- 50 Hz 陷波。
- 1–40 Hz 四阶 Butterworth 双向零相位带通滤波。
- 球面插值修复坏通道。
- 按任务起始标记提取 4 秒片段。
- 异常片段剔除，因此样本编号存在缺失。
- 逐通道去均值，采样率保持 300 Hz。

本队不再重复原始清洗。建模阶段只额外做每条 trial 的逐通道 z-score，以及为防御测试扰动而执行的 1–40 Hz 滤波。

## 最终模型

1. 18 通道协方差矩阵。
2. Riemann 均值参考下的 171 维切空间特征。
3. 261 维相对频带功率、谱熵和通道相关特征。
4. 目标 session 的协方差中心对齐。
5. 按任务选择不同切空间特征组合：
   - 闭眼：70% 切空间+稳健特征，20% 切空间+全部特征，10% 切空间+相对功率/相关。
   - 睁眼：切空间+全部特征。
   - 图像想象：切空间+全部特征。
   - SSVEP：60% 切空间+稳健特征，40% 切空间+全部特征。
6. Sinkhorn 调整测试类别分布。
7. 普通样本向高频扰动样本传播 30% 邻接概率。
8. 任务级拒识阈值优化对抗综合分。
9. session1 未知身份候选统一输出 0。
